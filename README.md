NOVA – Responsive Landing Page

🚀 About the Project

NOVA is a modern and responsive landing page created to showcase a creative technology brand. It features an attractive dark theme, gradient colors, smooth animations, and a clean user interface.

The website is designed to provide a visually engaging experience on desktops, tablets, and mobile devices.

✨ Features

- Responsive design for mobile, tablet, and desktop
- Modern dark theme with gradient effects
- Attractive hero section
- Animated visual elements
- Feature cards and statistics section
- Mobile navigation menu
- Contact section
- Smooth and user-friendly interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
